## **Installation**  
Project requires uv package manager

To install uv 
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

After cloning the repository, run the following
```
uv sync
source .venv/bin/activate
uv pip install -e .
```
## **How to Run**
```
## runs src/bit_detection/main.py

```
